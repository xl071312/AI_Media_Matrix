# Logic Architecture v0.3

Date: 2026-09-13
Owner: ChatGPT
Corpus basis: 85 verified logic samples.

## 1. Core decision

The earlier R1–R8 taxonomy is compressed into six primary reasoning engines. Trend and anomaly are retained as entry types rather than independent reasoning engines.

## 2. Six reasoning engines

### L1 Mechanism Derivation
Structure: `phenomenon/judgment -> why -> hidden mechanism -> consequence`.
Use when the viewer's main gain is understanding causality.
Typical domains: income traps, pricing, customer behavior, labor/time tradeoffs, business economics.

### L2 Cognitive Reframe
Structure: `common belief A -> actually B -> why the old frame fails -> new decision implication`.
Use when the main value is replacing the viewer's mental model.
Typical forms: '真正的X不是Y，而是Z', misconception correction, value redefinition.

### L3 State Transition
Structure: `state A -> desired state B -> transition cost/constraint -> bridge -> why someone pays / why the change sticks`.
This merges old R2 state transfer and R3 stage path where the core is movement between states.
Typical domains: ability monetization, income ladder, career transitions, productization.

### L4 System Loop
Structure: `action -> feedback -> information -> judgment -> iteration -> repeated action -> scale`.
Use when repeated learning, compounding, or operating-system thinking is central.
Typical domains: content, entrepreneurship, skill building, product-market iteration.

### L5 Constraint Optimization
Structure: `goal -> candidate paths -> real constraints -> eliminate -> best feasible path -> small reversible test`.
Use when the problem is not lack of ideas but choosing under time/capital/traffic/trust/capability constraints.
Typical domains: side business, startup choice, channel choice, income planning.

### L6 Case-to-Principle
Structure: `real case -> what actually happened -> mechanism -> principle -> transfer to viewer's situation`.
Use when a concrete business/person/event is the evidence carrier.
Typical domains: brand strategy, supply chain, user demand, entrepreneurship, field observation.

## 3. Entry types (not reasoning engines)

- X1 Contradiction / anomaly: '为什么结果和直觉相反？'
- X2 Self-location: ladder, coordinate, threshold, '你在哪一层？'
- X3 Trend signal: macro shift -> ignored variable.
- X4 Real case opening: person/company/event first.
- X5 Live demonstration: show result/artifact before explanation.
- X6 Strong question: explicit unresolved problem.

An entry must hand off into L1–L6; otherwise it is packaging without reasoning.

## 4. Evidence Architecture

- E1 Single real case: one traceable person/company/event.
- E2 Multi-case triangulation: two or more cases supporting the same mechanism.
- E3 Data ladder: ordered numbers/levels/thresholds that let the viewer compare or locate.
- E4 Field observation: first-hand or on-site observation used as evidence.
- E5 Market feedback: orders, presales, paying users, cheap experiments, real customer response.
- E6 Authority citation: expert/report/institution claim; must be fact-checked and never used as a substitute for mechanism.

Production preference for commercial claims: E5 > E1/E4 > E3/E2, while E6 depends heavily on source quality. This is an epistemic preference, not a proven engagement ranking.

## 5. Action Architecture

- A1 Playbook: ordered steps.
- A2 Live Demo: show how to execute and inspect the artifact/result.
- A3 Decision Rule: compact rule for choosing under uncertainty.
- A4 Script: reusable dialogue/question/prompt/interaction sequence.

Actionability is independent of reasoning depth. A tutorial can be highly actionable but cognitively shallow; a deep mechanism piece can be valuable without a long playbook.

## 6. Packaging / Memory devices

- P1 Taxonomy / map
- P2 Strong contrast / enemy label
- P3 Number breakdown
- P4 Equivalence Converter: convert abstract value into a familiar unit/cost/time/result
- P5 Self-Locating ladder
- P6 Mother Metaphor / cognitive carrier
- P7 Question Debt chain
- P8 Proxy Speech / identity framing
- P9 Principle stack
- P10 Case story

Packaging is not evidence and is not reasoning.

## 7. Four behavioral engines

### Comprehension Engine
Primary drivers: L1/L2/L3/L5 + concrete evidence.
Question: did the viewer's model of the problem change?

### Save Engine
Working definition: `Deferred Reuse`.
Primary drivers: A1/A2/A3/A4, P1/P3/P5, templates, checklists, models worth revisiting.
Question: is there something the viewer expects to use later?

### Share Engine
Working definition: `Proxy Speech + Useful Discovery`.
Primary drivers: P8 identity/stance, strong reframe, useful discovery, social-sendability.
Question: does sharing help the viewer express a view or help someone else?

### Comment Engine
Working definition: `Self Projection + Experience + Conflict + Practical Question`.
Primary drivers: P5 self-location, identity stakes, controversy, open diagnostic questions.
Question: does the viewer have a reason to insert themselves into the discussion?

## 8. Default Guanyu composition rule

Use one primary reasoning spine, not a pile of frameworks:

`1 primary L-engine + 1 evidence architecture + 1 action unit + 1 memory/packaging device`.

Recommended default for 4–5 min cognition video:

`conflict/anomaly -> Question Debt -> hidden mechanism -> real evidence -> constraint/counterexample -> decision rule -> memory model -> loop back to opening`.

## 9. Topic presets

### Ability Monetization
Default: `L3 State Transition + L5 Constraint Optimization + E5 Market Feedback + A3 Decision Rule`.
Core chain: `ability -> whose costly problem -> deliverable result -> payer -> trust -> transaction -> repeat purchase`.

### Money / Income Logic
Default: `L1 Mechanism + L2 Reframe + E1/E3 + A3`.

### Business Case
Default: `L6 Case-to-Principle + L1 Mechanism + E1/E3/E5 + A3`.

### Consumption / Middle-Class Anxiety
Default: `L2 Reframe + P5 Self-Locating + L1 Mechanism + P8 Proxy Speech when justified`.

### AI Business
Default: `L5 Constraint Optimization + E5 Market Feedback + L6 case + A3`.
Avoid tool-list content unless the tool is evidence for a business mechanism.

## 10. What was demoted from v0.2

- Old R6 Trend Opportunity Diagnosis -> entry type X3, then route to L1/L5/L6.
- Old R7 Anomaly Diagnosis -> entry type X1, then route to L1/L5.
- Stage path is not a standalone engine when it merely describes state transitions; route to L3.
- Generic list/taxonomy is packaging P1, not reasoning.

## 11. Non-negotiable methodological rules

- Reasoning != Evidence != Action != Packaging.
- Do not infer platform laws from uncontrolled engagement observations.
- Article prose may inform logic/written expression, not spoken Voice Profile.
- Strong factual claims must be marked FACT / INFERENCE / HYPOTHESIS during research and fact-checked before publication.
- Market response proves a demand signal, not guaranteed long-term profit or scalability.
