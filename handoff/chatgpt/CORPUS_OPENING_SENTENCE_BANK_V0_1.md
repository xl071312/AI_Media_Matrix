# Corpus Opening Sentence Bank v0.1

Purpose: source-grounded sentence shapes for Guanyu hook validation. Use as imitation reference for rhythm, simplicity and payload placement. Do not copy a creator's signature wording wholesale.

## Source-shaped examples

1. B002-003 — result first
   - `关于我用8000块，在半年内，赚到了130万...`
   - Shape: `小投入 + 短时间 + 大结果`

2. B002-010 — direct personal threat
   - `你们知道对钱没有概念有多可怕吗`
   - Shape: `你 + 日常对象 + 风险`

3. B002-012 — self-location
   - opening asks ordinary viewers what level their monthly income is, then asks where `5000块` ranks nationally.
   - Shape: `你现在的数字 + 放到更大范围 + 你排第几`

4. 7672991243072616697 — goal + error
   - `想赚100万，99%的人第一步就选错了`
   - Shape: `你想要的结果 + 大多数人做错 + 错在哪`

5. B002-007 — identity + blunt reframe
   - opens on `创业者们现在面临的最大问题...`
   - Shape: `某类人 + 现在最头疼的事 + 不是你以为的那个`

6. B002-013 — punchy metaphorical judgment
   - opening roughly: `上班是为了早日赎身，而不是为了当头牌`
   - Shape: `熟悉动作 + 反常但听得懂的判断`

7. B002-009 — belief challenge
   - opens roughly: `这年头还有人相信做自媒体可以月入过万...`
   - Shape: `你可能不信的事 + 我马上给你证据`

8. 7546212425998454074 — utility promise
   - `除了打工，至少还有16种赚钱的方法`
   - Shape: `普通人常见困境 + 明确数量 + 能带走的东西`

9. 7600957703851148773 — role-play paradox
   - opens by asking the viewer to imagine being a financial giant holding a lot of physical silver but wanting paper silver prices to fall.
   - Shape: `把你放进角色 + 一个拧巴选择`
   - Note: higher comprehension burden; not default for Guanyu mass audience.

## Common language traits

- `你 / 普通人 / 上班 / 钱 / 工资 / 老板 / 赚 / 亏 / 买 / 卖` appear before abstract theory.
- Numbers are used early when they create self-location or result contrast.
- Questions are concrete: `排第几`, `哪条最容易`, `你会怎么办`, `35块到底是什么概念`.
- Sentences are short and sometimes rough; they do not read like a written essay.
- A first sentence usually already delivers the reason to keep watching.

## Forbidden imitation mistake

Do not copy only surface fillers like `你想想`, `那问题来了`, `说白了` while keeping academic syntax underneath.

Correct order:
`ordinary noun/number/result -> simple question or conflict -> proof/example -> explanation`

Wrong order:
`abstract thesis -> analytical label -> elegant transition -> finally give example`
