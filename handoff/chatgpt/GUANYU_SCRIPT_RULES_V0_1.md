# Guanyu Script Generation Rules v0.1

Date: 2026-09-13
Owner: ChatGPT
Research basis: Logic Architecture v0.3 + Cross-Sample Hypothesis Matrix v0.1.

## 1. Product definition

Default content unit: 4–5 minute Chinese cognition/knowledge video.
Pre-TTS script target: roughly 900–1300 Chinese characters; TTS duration is the final authority.
The goal is not information density alone. Every video must produce an observable change in the viewer's mental model.

## 2. Required pre-script research

Before drafting the script, prepare:
- 5–10 references when the topic is factual/external.
- one logic map with 3–5 cognitive-gain nodes.
- claim ledger tagged FACT / INFERENCE / HYPOTHESIS.
- at least one concrete anchor: case, data ladder, field observation, live demo, or market feedback.
- one explicit viewer decision or judgment the video should improve.

Do not start from a catchy sentence and backfill logic.

## 3. Default 4–5 minute spine

### 0–5s: Conflict / anomaly
State a real tension, contradiction, or surprising result.
Do not give a generic motivational hook.

### 5–30s: Build Question Debt
Make clear what the viewer does not yet understand and why the intuitive answer is insufficient.

### 30–90s: Reveal the mechanism
Use L1/L2/L3/L5 as the main reasoning spine.
One section = one proposition.

### 90–180s: Earn the abstraction
Bring in real evidence: case, data, observation, transaction, experiment.
The evidence must do reasoning work, not merely decorate the script.

### 180–240s: Add constraints / counterexample
Show where the idea breaks, who it does not apply to, or what tradeoff matters.
Avoid universal claims.

### 240–285s: Give a decision rule / action unit
Prefer one strong A3 decision rule over a long generic list.
Use A1/A2/A4 only when the topic genuinely requires execution detail.

### Final 15–30s: Memory model + loop-back
Compress the idea into one model, formula, metaphor, ladder, or rule and return to the opening conflict.
Do not end with empty encouragement.

## 4. Cognitive Gain requirements

A standard episode should contain 3–5 cognitive-gain nodes.
Each node must answer one of:
- What did the viewer believe before?
- What new distinction or mechanism did they gain?
- What can they now predict or decide that they could not before?

If a paragraph adds facts but no new distinction, mechanism, evidence, constraint, or decision rule, cut it.

## 5. Minimum structural thresholds

Default target:
- >=2 explicit comparisons.
- >=2 logic visuals in the shot plan.
- >=1 real case/fact anchor.
- >=1 constraint/counterexample.
- >=1 decision rule or reusable model.
- hook within first 5 seconds.
- first real cognitive conflict within 30 seconds.

These are production defaults, not immutable platform laws.

## 6. Reasoning selection rule

Choose exactly one primary L-engine as the spine.
A secondary engine may support it, but do not stack frameworks merely to sound deep.

Topic presets:
- 能力变现: L3 + L5; evidence E5; action A3.
- 赚钱逻辑/普通人收入: L1 + L2; evidence E1/E3; action A3.
- 商业案例: L6 + L1; evidence E1/E3/E5; action A3.
- 消费/中产: L2 + L1 + P5 self-location; optional P8 proxy speech.
- AI商业: L5 + L6 + E5; avoid tool catalogues.

## 7. Guanyu ability-monetization canonical chain

Use this as the default causal map, not as fixed wording:

`能力 -> 对方的高成本问题 -> 可交付结果 -> 付款者 -> 信任 -> 交易 -> 复购/重复交付`

A script that stops at '你会什么' or '哪里有信息差' is incomplete.

## 8. Evidence rules

Prefer evidence that closes an uncertainty:
- E5 market feedback for demand claims.
- E1/E4 for concrete mechanism.
- E3 for scale/comparison/self-location.
- E6 authority citation only with source verification.

Never transform an unverified claim into a FACT through confident prose.
For finance, medical, policy, legal, employment, and rapidly changing platform claims, fact-check before publication.

## 9. Save / Share / Comment design must be separated

### To earn Save
Create Deferred Reuse:
- checklist
- decision rule
- comparison table
- template
- prompt/script
- model/ladder
- live demonstration the viewer may replicate

### To earn Share
Create social-sendability:
- a precise reframe the viewer wants to send to someone
- proxy speech that articulates a group experience
- a genuinely useful discovery
Do not manufacture outrage.

### To earn Comment
Create legitimate entry points:
- self-location question
- lived-experience contrast
- disputable but evidence-backed claim
- practical diagnostic question
Do not use empty '你怎么看'.

## 10. Oral expression rules

The script must sound spoken, not essay-like, but the Voice Profile is not yet frozen.
Candidate connective phrases may be used naturally when they fit logic:
- 你想一下
- 问题就在这儿
- 为什么
- 你注意这个区别
- 再往后想一步
- 换句话说
- 其实不是
- 那问题来了

Do not force frequency, imitate a single creator, or repeat signature phrases mechanically. H04 remains deferred until the spoken corpus is larger.

## 11. Sentence and paragraph rules

- Prefer short spoken clauses.
- One paragraph should usually carry one cognitive function.
- Use concrete nouns and verbs over abstract business jargon.
- Define terms before using them as conclusions.
- Avoid three consecutive abstract sentences without a case/number/example.
- Avoid stacked synonyms pretending to add depth.
- Avoid '在这个时代/在当下/随着社会发展' openings unless factually necessary.

## 12. Anti-AI-sludge rules

Reject or rewrite passages that:
- repeat the conclusion in different words.
- list five points where two would explain the mechanism better.
- use vague labels such as '底层逻辑' without actually showing a causal chain.
- use fake precision or unsupported percentages.
- invent composite anecdotes presented as real cases.
- move directly from correlation to causation.
- sound like motivational copy rather than analysis.

## 13. Visual logic rules

Visual target for cognition video:
- ~60% logic visuals
- ~25% supporting footage
- ~15% keywords/subtitle animation

Preferred logic visuals:
- before/after comparison
- causal chain
- flowchart
- funnel
- state transition
- constraint matrix
- ladder
- curve
- formula
- timeline
- decision tree

Do not let generic AI B-roll carry the explanation.

## 14. Shot-plan mapping

Every cognitive block should declare a visual job:
- DEFINE: label/diagram the concept.
- COMPARE: side-by-side difference.
- CAUSE: causal arrows/mechanism.
- LOCATE: ladder/coordinate.
- PROVE: case/data/evidence.
- DECIDE: decision rule/tree.
- REMEMBER: final model/metaphor.

If a shot is only decorative, it should not displace a needed logic visual.

## 15. Draft QA gate

A script does not advance to production unless all are true:
1. Primary L-engine identifiable in one sentence.
2. 3–5 cognitive-gain nodes present.
3. At least one evidence anchor is traceable.
4. FACT/INFERENCE/HYPOTHESIS boundaries are clear.
5. At least one meaningful constraint/counterexample is included.
6. Action unit is concrete or intentionally omitted for a pure viewpoint piece.
7. Ending compresses the reasoning into a reusable model.
8. The hook is paid off by the ending.
9. No unsupported high-risk claims.
10. Spoken rhythm survives read-aloud / TTS test.

## 16. Production principle

The default formula is not 'hook + three tips'.
It is:

`one reasoning spine + one proof architecture + one action unit + one memory device`.

Market-proven expression can influence packaging, but Guanyu's final voice and reasoning must remain original rather than copied from any single benchmark creator.
