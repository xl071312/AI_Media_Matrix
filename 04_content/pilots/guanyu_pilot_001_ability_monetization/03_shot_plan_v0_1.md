# Pilot 001 Shot Plan v0.1

Visual principle: logic-first. Target mix ~60% logic visuals / 25% supporting footage / 15% keyword-subtitle animation.

| Time | Cognitive Job | Narration Function | Visual | Type |
|---|---|---|---|---|
| 0–5s | CONTRAST | 能力不差却赚不到钱 | Split screen: left = skill badges, right = buyer paying for a solved problem; center text `能力 ≠ 收入` | Logic visual |
| 5–20s | QUESTION | 我会什么 vs 谁的问题值钱 | Two-question cards; first fades, second enlarges | Logic visual |
| 20–45s | PROVE | User first-hand business case | Before/after mini-P&L card: `半年约-6万 -> 接手后转正 -> 后续约4万/月*`; footnote `publish only after user verification` | Logic/data visual |
| 45–75s | CAUSE | 利润改善来自人效/成本/流程损耗 | Leakage diagram with three holes: 人效 / 成本 / 流程 | Logic visual |
| 75–95s | REFRAME | 会管理 vs 拉回盈利 | Side-by-side: `能力标签` vs `可购买结果` | Logic visual |
| 95–125s | MAP | 四道门 | Flow: 高成本问题 -> 结果 -> 付款人 -> 信任 | Logic visual |
| 125–165s | COMPARE | “会AI”与“交付结果”区别 | Example cards: vague skill statement vs concrete workflow outcome | Logic visual |
| 165–200s | CONSTRAINT | 有价值不等于能成交 | Decision-chain funnel: problem owner -> budget owner -> decision maker -> access | Logic visual |
| 200–235s | FRICTION | 信任问题 | Buyer thought bubbles: `为什么是你?` `失败怎么办?` `先付多少?` | Logic visual + light character animation |
| 235–260s | DECIDE | 低风险第一次交易 | Decision tree: 大合同 X -> 诊断 / 小试点 / 短周期优化 ✓ | Logic visual |
| 260–295s | LOOP | 一次项目如何变复购 | Ladder: 经验 -> 清单 -> 指标 -> 模板 -> 流程 -> 复盘机制 | Logic visual |
| 295–330s | ACTION | 三个问题 | Full-screen three-question checklist; each appears with one icon | Logic visual |
| Final | REMEMBER | 能力到复购链条 | Full chain: `能力 -> 高成本问题 -> 结果 -> 付款人 -> 信任 -> 交易 -> 复购`; return to opening split screen | Logic visual |

## Supporting footage candidates

Use only between logic beats, never instead of logic:
- office / retail operations footage for the real-case section
- person reviewing spreadsheet/process map
- buyer/seller meeting silhouette or stylized AI character interaction

## Subtitle rules

- Do not subtitle every spoken word as a design layer; base subtitles remain functional.
- Highlight only key distinctions: `能力`, `结果`, `付款人`, `信任`, `交易`, `复购`.
- Formula/chain visuals should remain on screen long enough to be read.

## Production note

The personal business-case numbers are not cleared for publication until the user confirms exact wording and values. If not confirmed, replace the numeric card with a non-numeric before/after case description rather than inventing or smoothing numbers.
